# Data Cleaning and Preparation

## Project Overview
This project focuses on cleaning and preparing a sales dataset using Microsoft Excel.

## Dataset
The dataset contains order information such as customers, products, categories, dates, quantities, prices, cities, payment methods and order status.

## Cleaning Performed
- Handled missing values.
- Removed duplicate records.
- Standardized city names.
- Standardized product names.
- Standardized payment methods.
- Corrected invalid quantity values.
- Corrected unit price formatting.
- Standardized date formats.
- Created a Total Sales column.

## Tool Used
Microsoft Excel

## Outcome
The dataset was cleaned and prepared for further data analysis.
# Data Cleaning & Exploratory Data Analysis Internship Project

## About the Project

This project was completed as part of my data analytics internship.

The project includes:
- Data cleaning and preparation
- Exploratory Data Analysis (EDA)
- Statistical analysis
- Monthly sales analysis
- City-wise sales analysis
- Data quality and anomaly analysis
- Charts and visualizations
- Business insights

## Task 1 – Data Cleaning

The raw sales dataset was cleaned using Microsoft Excel.

The cleaning process included:
- Identifying missing values
- Handling unknown/inconsistent values
- Removing duplicate records
- Correcting date formats
- Checking data types
- Standardizing values
- Checking sales-related errors

## Task 2 – Exploratory Data Analysis

The cleaned dataset was analyzed to identify trends, patterns and anomalies.

The analysis included:
- Overall sales analysis
- Monthly sales analysis
- City-wise sales analysis
- Product/category analysis
- Order status analysis
- Payment method analysis
- Data quality and anomaly checks

## Key Insights

1. Monthly sales were analyzed to identify changes and trends over time.
2. City-wise sales analysis was performed to understand sales distribution.
3. Product/category performance was compared using sales data.
4. Order and payment data were checked for inconsistencies.
5. Zero-sales and other unusual records were identified during anomaly analysis.
