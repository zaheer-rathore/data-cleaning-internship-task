# Data Cleaning and Preparation

## Project Overview
This project focuses on cleaning and preparing a sales dataset using Microsoft Excel.

## Dataset
The dataset contains order information such as customers, products, categories, dates, quantities, prices, cities, payment methods and order status.

## Cleaning Performed
- Handled missing values.
- Removed duplicate records.
- Standardized city names.
- Standardized product names.
- Standardized payment methods.
- Corrected invalid quantity values.
- Corrected unit price formatting.
- Standardized date formats.
- Created a Total Sales column.

## Tool Used
Microsoft Excel

## Outcome
The dataset was cleaned and prepared for further data analysis.

## 🔎 Key Insights

### Insight 1 — Electronics dominated sales
Electronics generated ₹10.30 million in sales, making it the largest category in the dataset.

### Insight 2 — Laptops were the highest-selling product
Laptop sales reached approximately ₹5.16 million, making laptops the strongest individual product by sales value.

### Insight 3 — Total sales exceeded ₹11 million
The dataset generated total sales of ₹11,366,007 across 300 orders.

### Insight 4 — Order statuses showed a significant number of non-completed orders
The dataset contained 103 cancelled orders and 101 pending orders, compared with 91 completed orders.

### Insight 5 — The dataset contained data-quality issues
During the cleaning and analysis process, unknown values, blank values, inconsistent dates, and zero-sales records were identified and reviewed.
